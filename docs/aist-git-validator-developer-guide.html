03 / 07Initial setup

Connect your Jira account.

Run setup once, then enter your organization's Jira URL, your email, and a valid Atlassian API token.

What you’ll need

Jira base URL
Your organization's Jira address
Jira email
The email associated with your Jira account
Atlassian API token
A valid token for your account

API tokens are sensitive. Never share them or commit them to source control.
